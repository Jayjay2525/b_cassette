# B_Cassette 📼

A photo memory app inspired by cassette tapes — turn your everyday photos into A-cuts and B-cuts, scored with AI-generated music.

> iOS app built with SwiftUI. Currently in App Store review.

## Features

- Organize photos into cassette tapes with A-cut / B-cut concept
- AI-generated soundtrack based on your photo vibes (Claude + MusicGPT)
- Custom cassette design with font and color selection
- Export as video to Instagram Stories or camera roll
- Push notifications when your AI music is ready

## Tech Stack

- **SwiftUI** (iOS 17+)
- **Supabase** — auth, database, edge functions
- **Anthropic Claude API** — keyword extraction from photos
- **MusicGPT API** — AI music generation
- **APNs** — push notifications
